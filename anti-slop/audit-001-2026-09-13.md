# Audit animasi tahapan mesin

Lingkup: perubahan scroll tab dan bola logo, diperiksa setelah implementasi sesuai permintaan pengguna. Bukan audit ulang seluruh landing page.

Tidak ada temuan yang memerlukan perubahan tambahan dalam lingkup yang diperiksa.

- R-19: transisi konten mengikuti arah navigasi; indikator menunjukkan tahap aktif. Gerak bola diminta langsung oleh pengguna dan berhenti di luar viewport melalui IntersectionObserver.
- R-26: browser memverifikasi scroll maju Riset → Penawaran → Landing page → Creative → Campaign → Optimasi, lalu keluar ke section berikutnya. Arah balik juga diverifikasi satu tahap per gesture sampai kembali ke Riset.
- R-03 / R-34: layout desktop 1440×900 dan ponsel 390×844 diperiksa; ponsel tidak memiliki overflow horizontal. Bola tool tampil di bawah detail tahap pada ponsel. Tombol native tetap mendukung keyboard. Reduced motion menonaktifkan animasi dan penahanan scroll.
- Beban: memakai WebP yang sudah ada (sekitar 16–20 KB per aset), lazy loading bawaan Image, CSS transform/opacity, tanpa dependency atau loop JavaScript per frame tambahan.

Validasi: build produksi dan TypeScript berhasil; git diff --check bersih.

Batas pemeriksaan: gestur sentuh pada perangkat fisik dan perubahan preferensi reduced motion belum diuji langsung; perilakunya diperiksa pada kode.
